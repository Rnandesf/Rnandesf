## 01 / About Me

I'm **Rodrigo Fernandes**, a developer from Portugal working across **frontend, backend, data, and AI integration**.

My current work brings together interactive dashboards, Python APIs, analytical databases, and assistants that connect language models with application data and documentation.

I'm particularly interested in how these components fit together: from collecting and storing information to making it accessible through clear interfaces and useful tools.

## 03 / Current Focus

### Monitoring, Data Visualization & AI-Assisted Exploration

Working on a monitoring platform that combines:

- **Interactive dashboards** for exploring measurements and historical data.
- **Geospatial visualization** for displaying positions and telemetry.
- **Backend services** for ingestion, validation, authentication, and querying.
- **Analytical and object storage** for measurements and archived data.
- **AI integration through MCP and RAG** to connect assistants with application tools and documentation.
- **Automated testing** across backend logic and frontend interactions.

**Core stack:** React · TypeScript · Python · FastAPI · PostgreSQL · ClickHouse · Docker
